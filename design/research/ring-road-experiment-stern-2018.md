## 1. 一句话结论

在一条 260 m 的单车道环路上，20 多辆人类驾驶的车会**在没有任何瓶颈的情况下**自发形成停走波；
只要控制其中 **1 辆**车的纵向速度，就能把波消掉：车速标准差最多降低 80.8%，油耗最多降低 42.5%，
急刹几乎消失，吞吐量最多提升 14.1%。作者据此认为，**渗透率不到 5% 的自动驾驶车就足以调控车流**，
远早于大多数车辆实现自动驾驶的那一天（摘要、§5）。

## 2. 背景与定位（§1）

- **Sugiyama 等 2008 / Tadaki 等 2013**（日本）：首次用实验证明，没有瓶颈、没有变道，停走波也会因人类驾驶行为自发出现；但没有给出消除办法。
- **本研究**：完整复刻 Sugiyama 的设置，让波由人类司机“自然”产生，再用 1 辆车去消除它。
- **与“吸收驾驶”（jam-absorption driving）的关系**：Nishi 等 2013 年提出“慢进快出”的理论，Taniguchi 等用 5 辆车做过演示，但那次的波是领头车人为制造的。本研究的控制器与它们不同。
- **范式转变**：从“定点控制”（匝道信号、可变限速龙门架）转向“随车流移动的执行器”（Lagrangian actuators）。这和交通**感知**从固定线圈转向手机 GPS 浮动车的过程相对应：3–5% 的浮动车就足以估计路网状态。

## 3. 实验设置（§2）

| 项目 | 原文 |
|---|---|
| 场地 | 亚利桑那州图森，平坦沥青场地，单车道圆环，**半径 41.4 m（到车道中心），周长 260 m**；只用小锥桶和 3 cm 高的橙色标记划定 |
| 方向 | 逆时针（照顾美国车更大、左舵驾驶） |
| 车辆 | 22 辆车的车队（论文表 5：Malibu、Grand Caravan、Suburban、Silverado 等，车长 4.44–5.70 m）。实验 A、B 用 21 辆，实验 C 用 22 辆 |
| 受控车 | 亚利桑那大学的 **CAT Vehicle**（2009 款 Ford Escape Hybrid），可以在人工车速和自动车速之间切换；**方向盘始终由人掌控**，自动的只有纵向车速 |
| 其他司机 | 亚利桑那大学员工，受过安全驾驶培训，没有其他特殊训练 |
| 数据 | 场地中心的 360° 摄像机 → 计算机视觉提取每辆车的轨迹；每辆车接 OBD-II，记录瞬时油耗 |
| 时长 | 每次 7–10 分钟（避免疲劳）；从均匀间距、静止状态出发；停走波出现后**至少等 45 秒**再开启控制 |
| 流程 | 准备 → 人员撤离 → 汽笛：挂 D 档 → 汽笛：开始 → 汽笛：停车 → 结束 |

**给人类司机的原话（§2.2）**：“像高峰期那样开。跟住前车，不要落后。不要超车，不要撞前车。始终安全驾驶，不要贴太近。**但如果前面拉开了空档，要重点去追上。**”

这条指令是刻意设计的：目的是不让人类司机自己去平滑车流，从而确保观察到的消波效果只来自 CAT Vehicle。

**停走波判定（附录 5.2）**：每个时刻所有车车速的标准差超过 **2.5 m/s**，就认为出现了停走波。

## 4. 控制器（§3）

三种控制器的共同结构：

1. 以 30 Hz 测量与前车的车距 Δx（自己前保险杠到前车后保险杠的距离），并求出相对速度 Δv = d(Δx)/dt。
2. 估计前车速度 v_lead = v_AV + Δv。
3. 根据设定速度 U、车距和速度算出指令速度 v_cmd。
4. 由底层控制器把 v_cmd 转成油门或刹车。

核心思想：**按车流平均速度开**。这样走的距离一样，但加减速少得多。另外需要额外的逻辑，防止车距过小（不安全）或过大（在多车道路上会诱发变道）。

### 4.1 FollowerStopper（§3.1，实验 A）

在 Δx–Δv 相平面上，用三条抛物线把空间分成“停车区 / 两段过渡区 / 安全区”：

```
Δx_k = Δx0_k + (Δv⁻)² / (2·d_k),   k = 1,2,3,   Δv⁻ = min(Δv, 0)
Δx0 = 4.5 / 5.25 / 6.0 m,   d = 1.5 / 1.0 / 0.5 m/s²

v = min(max(v_lead, 0), U)
v_cmd = 0                                   若 Δx ≤ Δx1
      = v · (Δx − Δx1)/(Δx2 − Δx1)          若 Δx1 < Δx ≤ Δx2
      = v + (U − v)(Δx − Δx2)/(Δx3 − Δx2)   若 Δx2 < Δx ≤ Δx3
      = U                                   若 Δx > Δx3
```

例：以 Δv = −3 m/s 追近前车时，三条边界分别扩大到 7.5 / 9.75 / 15 m。

**需要外部给定 U**：实验中由研究人员观察车流后逐步调整。

### 4.2 PI with saturation（§3.2，实验 C）

```
U        = 自身过去 m 个车速样本的平均值（m 对应 38 s，约跑一圈的时间）
v_target = U + v_catch · clip((Δx − g_l)/(g_u − g_l), 0, 1)
v_cmd    ← β(α·v_target + (1−α)·v_lead) + (1−β)·v_cmd
α        = clip((Δx − Δx_s)/γ, 0, 1),   β = 1 − α/2
g_l = 7 m,   g_u = 30 m,   v_catch = 1 m/s,   γ = 2 m,   Δx_s = max(2 s × Δv, 4 m)
```

两端的“饱和”：

- 车距小时，完全跟随前车速度（为了安全）；
- 车距大时，最多比平均速度快 1 m/s 去追（防止空档越拉越大）。

**不需要任何外部输入**。参数是在仿真（用拟合人类司机数据的模型）和跟车实测中确定的。

### 4.3 底层控制（§3.3）

两个 PID 模式之间切换：

- 指令速度比当前车速低 0.25 m/s 以上时，用**刹车模式** h2：上升时间约 0.8 s，超调 11%，稳定时间约 1.94 s；
- 其他情况用**油门模式** h1：上升时间约 1.6 s，超调 5%，稳定时间约 5.52 s；
- 控制频率 20 Hz。

### 4.4 训练过的人类司机（§3.4，实验 B）

由合著者 M. Bunting 驾驶：保持外部观察者给定的速度（按上一圈的平均车速计算，以 mph 告诉他），只在为了避免追尾时才减速。

## 5. 结果（§4）

### 5.1 指标定义（§4.1）

- **车速标准差 σ**：对时段内所有车、所有时刻的车速一起计算的样本标准差。
- **吞吐量**：`q = (n / L) · v̄`，其中 L = 260 m。
- **油耗**：OBD-II 瞬时油耗，按时段和车辆平均，单位 L/100km。
- **急刹事件**：减速度峰值超过阈值 τ，且两侧都回落超过 τ 才算一次；按车辆数和行驶距离归一化，单位“次/车/km”。τ 取有波时段内所有车减速度标准差的平均值。

### 5.2 三次实验的对比（论文表 3：刚出现波的时段 WS vs. 控制开启后最好的时段 CA）

| 实验 | 方式 | 车速标准差 | 油耗 (L/100km) | 急刹 (次/车/km) | 吞吐 (veh/h) |
|---|---|---|---|---|---|
| A（21 辆） | FollowerStopper | 3.31 → 0.64（**−80.8%**） | 24.6 → 14.1（**−42.5%**） | 8.58 → 0.12（**−98.6%**） | 1827 → 2085（**+14.1%**） |
| B（21 辆） | 训练过的人类司机 | 2.36 → 1.19（−49.5%） | 21.8 → 17.0（−22.1%） | 9.50 → 2.27（−76.2%） | 1828 → 2008（+9.8%） |
| C（22 辆） | PI 饱和控制 | 3.85 → 1.74（−54.7%） | 29.0 → 20.9（−28.1%） | 9.66 → 2.47（−74.4%） | 1755 → 1711（**−2.5%**） |

### 5.3 实验 A 时间线（论文表 1）：设定速度 U 的“倒 U 形”

| 时段 | 开始 (s) | U (m/s) | σ (m/s) | 油耗 | 急刹 | 吞吐 |
|---|---|---|---|---|---|---|
| 实验开始 | 0 | — | 1.87 | 18.8 | 1.66 | 1809 |
| 停走波出现 | 79 | — | 3.31 | 24.6 | 8.58 | 1827 |
| 开启控制 | 126 | 6.50 | 1.69 | 18.0 | 3.45 | 1780 |
| | 222 | 7.00 | 0.67 | 15.0 | 0.21 | 1915 |
| | 292 | **7.50** | **0.64** | **14.1** | **0.12** | **2085** |
| | 347 | 8.00 | 1.56 | 17.7 | 2.50 | 1952 |
| | 415 | 7.50 | 1.14 | 16.7 | 0.31 | 1938 |
| 关闭控制 | 463 | — | 1.44 | 17.4 | 2.95 | 2133 |

论文原话的要点：

- U = 7.5 m/s 时，CAT Vehicle 的速度几乎正好等于车流平均速度，**所以它根本不需要减速**。
- 把 U 提到 8.0 m/s 后，它平均比车流快，**这必然会重新引发停走波**；不过即便如此，仍然好于完全不控制。
- 关闭控制后，停走波重新出现。

### 5.4 其他观察

- **实验 B**：人类执行同样的策略，也能消波，但不如自动控制精确（车速以 mph 取整，反应更粗）。
- **实验 C**：第一道波被消除后，控制期间又冒出了第二道波，随后也被压了下去。PI 控制只用本车信息，“消波不如实验 A 完美”，并且**略微降低了平均车速**。
- **控制前的代价**（实验 C）：停走波出现后，与它出现前的平稳阶段相比，σ 上升 37.7%，油耗上升 63.8%，吞吐下降 18.8%。

## 6. 作者自己写明的局限与展望（§5）

- 实验只代表**单车道**路段。在多车道路上，**变道本身就是新的触发源**；而控制车留出的大空档会**诱发加塞**，削弱控制效果。论文指出，实验 A 的控制器在消波之后并没有一直保持大车距。
- 效果可以用“已有的 ACC + 智能基础设施或车联网提供 U”来实现。
- 作为对比：一套成功的可变限速系统大约只能提升 5% 的通行能力，而且管不到两个控制点之间的车流动态。
- 与机器人编队不同，这里的自动驾驶车和人类**没有合作**，而是在抵消人类制造不稳定的倾向。

## 7. 设计推论（以下是我们的推论，不是论文结论）

1. **核心对手是“涌现”，不是障碍物。** 堵车可以完全由司机行为产生，所以模拟必须基于跟驰模型（OV-FTL 或 IDM）加噪声，而不是写死的脚本。人类司机“追车的积极程度”就是不稳定的来源，可以作为城市或区域的难度参数。
2. **设定速度 U 是一条有悬崖的倒 U 曲线。** U 太低：能消波，但拖慢整体；U 恰好等于车流真实均速：几乎零成本；U 稍高：自己就成了新的波源。这是现成的调参谜题，而且有真实数据背书。
3. **信息是资源。** 三个实验正好构成一条升级线：人工代驾（B，便宜、粗糙）→ 本地自估（C，不需要基础设施、稳定、略降速）→ 外部给定 U（A，效果最好，需要数据或通信设施）。
4. **必须持续在场。** 关闭控制，波就回来；控制期间也会冒出新波。CyberCab 的作用是“持续覆盖”，天然适合做成长期运营问题，而不是一次性解谜。
5. **渗透率锚点：1 辆控制约 20 辆（< 5%）。** 可以用作“每段路的最低覆盖率”，超过之后收益递减。
6. **代价和反制。** 消波需要留出缓冲空档；到了多车道就会被加塞（论文自己承认的未解问题），可以作为后期关卡的机制。另一层张力是：CyberCab 乘客想快，城市整体需要它“慢一点”。
7. **固定设施和移动执行器对比。** 可变限速约 +5%，并且只管得到控制点附近；CyberCab 可以随车流移动。两者可以作为玩家的两类工具。
8. **可直接复用的 UI。** 时空轨迹图（论文图 3a）、车速 ±σ 带（图 3b）、瞬时 σ 加 2.5 m/s 阈值线（图 6），分别可以做成“交通雷达”、车流平稳度和停走波警报。
9. **数值不要照搬。** 节油 42.5% 是在约 25 km/h、高密度、严重走走停停的条件下测得的，不代表城市平均效果；做平衡时要按场景重新标定。

## 8. 原型标定摘要

详见 `prototypes/ring-road-concept/README.md`。本原型用 OV-FTL 加噪声模拟人类司机，FollowerStopper 和 PI 控制器的参数照搬论文：

- 停走波在开局 50–80 s 出现，σ 约 2.5–3.1 m/s。
- FollowerStopper 最优 U ≈ 6.0–6.2 m/s：σ 约 −80%，油耗约 −28%，吞吐 +2~7%；U = 6.3 时出现悬崖。
- PI 控制：σ 约 −45%。
- 规律和论文一致，但本仿真的整体车速比论文低约 1.3 m/s，油耗是估算模型，只能看相对变化。
