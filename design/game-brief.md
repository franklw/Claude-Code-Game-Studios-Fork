# Game Brief: 路权（暂定名）

**One-sentence pitch:** 经营一家 Robotaxi 公司，用车队赢得乘客，用政策影响力说服市议会，把一座被汽车和停车场占满的城市，一步步改造成公园城市。

## Core loop
- **运营**：调车队规模、车费、拼车，换来资金；服务好坏影响市民满意度。
- **观察**：看拥堵从哪来、哪里在占道停靠、各片区停车需求下降了多少。
- **提案**：花资金和政策影响力向市议会提案，比如买下路边车位改成上下客区，或把地面停车场改成公园。
- **收获**：城市变了，满意度和影响力上升，解锁更大的提案，回到"运营"。

## Player goal & fail state — what "working" looks like
- **目标**：在规定年限内（例如 2028–2040）完成城市转型目标：门到门时间下降、停车场改造面积达标、满意度不低于目标线；最后用"城市秩序指数"综合评分。
- **失败**：政策影响力跌到 0，市议会吊销运营牌照；或资金破产。
- **一局完整的感觉**：每过一年有一份年度报告，告诉玩家这一年城市变了什么、为什么。

## MVP — what must exist to be the game
1. 交通和出行模拟：沿用原型 `prototypes/robotaxi-traffic-concept/`（路段排队、停车与找车位、市民自选出行方式、拼车、门到门指标）。
2. 运营杠杆：车队规模、车费、拼车。
3. 三项资源：资金、政策影响力、分人群满意度（司机、没车的人、周边居民）；占道停靠降低满意度。
4. 提案与市议会：提案卡写明成本、预测影响、受益者和受损者；市议会表决。
5. 两类停车转化：路边车位 → 上下客区；地面停车场 → 公园。
6. 按年推进：Robotaxi 越普及，停车需求越低；每年一份年度报告。
7. 一张地图、一个场景目标（例如"2032 年前改造 3 个地面停车场，满意度不低于 60"）。

## Out of scope — not building this
- Robobus 和公交上路（MVP 后第一个大扩展：后期重大升级，消耗大量影响力和资金）。
- 大楼停车位改造（第二个扩展，和 Robobus 一起构成后期"收获期"）。
- 多家运营商竞争、竞争对手 AI。
- 多张地图、真实城市地图导入。
- 3D 画面、多人联机。
- 信号灯和转向冲突等交通细节。

## Build order
1. 按年推进 + 停车需求下降曲线 + 地面停车场改公园：先验证"看准时机改造"是否好玩，这是满足感的来源。
2. 三项资源，占道停靠接到满意度。
3. 提案卡和市议会表决。
4. 路边车位购买，改成上下客区。
5. 年度报告、场景目标、失败条件。
6. 可读性打磨：改造前后对比，地图由灰变绿。

---
**Who it's for / what they feel:** 喜欢《Monopoly Tycoon》《城市：天际线》《Mini Metro》的策略模拟玩家；每局 30–60 分钟，享受"看准时机一次大改造，灰色停车场变成绿色公园"的满足感。

**Art & audio direction:** 俯视 2D，类似《Monopoly Tycoon》的街区色块和地标图标；深色地图上流动的车流光点，停车场的灰与公园的绿强烈对比；轻电子环境音。

**Reference game:** 《Monopoly Tycoon》——MVP 只保留俯视街区地图、地块分组，以及"拥有和改造地块"的手感；不做商店经营和竞争对手 AI。
