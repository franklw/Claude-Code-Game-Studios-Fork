# 环路吸波原型（ring-road-concept）

**状态**：in-progress（已构建，待试玩）

## 要回答的问题

> 如果玩家调 CyberCab 的设定速度 U 并切换控制模式，他们会获得“一辆车让整个环路安静下来”的满足感——
> 判断标准：**3 分钟内找到最优 U**（全环路车速标准差 < 1.0 m/s，且吞吐量不低于有停走波时），
> 并且**主动重来或尝试其他模式**。

**风险最大的假设**：找到最优点之后就没事可做了——只有一次“啊哈”，没有可重复的循环。

## 怎么运行

双击 `prototype.html`，用任意现代浏览器打开即可（无需服务器、无需安装）。

建议的第一次玩法：不看下文，直接打开，按 2× 或 4× 倍速看停走波形成，然后自己摸索。

## 原型里有什么

- 260 m 单车道环路，21 辆车（车长取自论文表 5），其中 1 辆是红色 CyberCab
- 三种 CyberCab 模式：人类驾驶 / FollowerStopper（需要玩家给 U）/ PI 饱和控制（自己估算 U）
- 时空轨迹图（最近 180 s）、瞬时车速标准差曲线（2.5 m/s 停走波阈值、1.0 m/s 目标线）
- 近 30 秒的指标：σ、平均车速、吞吐量、估算油耗、急刹次数
- 实验记录表：每次切模式或松开 U 滑块都会新开一行，对照论文表 1
- “让一辆车急刹 1.5 秒”干扰按钮、倍速、暂停、重来（同一组司机）、换一组司机
- **刻意不做**：多车道、加塞、关卡、菜单、计分系统、音效

## 仿真模型（与论文的差异要心里有数）

| 部分 | 实现 | 来源 |
|---|---|---|
| 人类司机 | OV-FTL 跟驰模型：`a = α(V(s) − v) + β·Δv/s²`，`V(s) = 9.75·(tanh(s/3.05 − 2) + tanh 2)/(1 + tanh 2)`，α = 0.5 ± 0.1，β = 20，加 OU 加速度噪声（σ = 0.15 m/s²，τ = 1 s），带近距离防撞制动 | 研究团队配套仿真使用的模型族；参数为本原型自行标定 |
| FollowerStopper | 论文式 (1)(2)，参数原样：Δx0 = 4.5 / 5.25 / 6.0 m，d = 1.5 / 1.0 / 0.5 m/s² | 论文 §3.1 |
| PI 饱和控制 | 论文式 (3)–(5)，参数原样：38 s 窗口，g_l = 7 m，g_u = 30 m，v_catch = 1 m/s，γ = 2 m，Δx_s = max(2·Δv, 4 m) | 论文 §3.2 |
| 底层控制 | 一阶跟踪：刹车模式 τ = 0.36 s，油门模式 τ = 0.73 s（按论文给的上升时间换算） | 论文 §3.3 |
| 油耗 | 简化功率模型（怠速 + 牵引功率），**只能看相对变化**，不是论文的 OBD-II 实测 | 本原型自拟 |
| 急刹事件 | 减速度峰值 > 1.5 m/s²，回落到 0.75 m/s² 以下才算结束 | 论文用的是数据自适应阈值 τ，这里用固定值 |
| 停走波判定 | 瞬时车速标准差 > 2.5 m/s | 论文附录 5.2 |

### 标定结果（Node 无界面批量运行，3 个随机种子，控制开启 90 s 后统计 120 s）

| 情况 | σ (m/s) | 平均车速 | 吞吐 (veh/h) | 油耗估算 | 急刹 (次/车/km) |
|---|---|---|---|---|---|
| 全人类驾驶（有波） | 2.5–3.1 | 5.8–5.9 | 1676–1723 | 19.0–20.6 | 7.7–11.9 |
| FollowerStopper U = 5.0 | ≈ 0.5 | 5.0 | ≈ 1455（−14%） | ≈ 15.5 | ≈ 0.8 |
| FollowerStopper U = 6.0 | 0.58–0.67（约 −80%） | 6.0 | ≈ 1745（+2~4%） | ≈ 14.3（约 −28%） | 1.1–2.1 |
| FollowerStopper U = 6.2 | 0.75–0.81 | 6.2 | ≈ 1797（+5~7%） | ≈ 14.4 | 2.2–2.8 |
| FollowerStopper U = 6.3 | 1.43–1.59（**悬崖**） | 6.0 | ≈ 1740 | ≈ 17.5 | 7–9 |
| FollowerStopper U = 7.0 | ≈ 2.3（波还在） | 5.9 | ≈ 1705 | ≈ 17.6 | ≈ 5.5 |
| PI 饱和控制 | 1.53–1.57（约 −45%） | 6.0 | ≈ 1740 | ≈ 17.0 | 7–9 |

- 停走波在开局 50–80 s 自发出现（论文实验为 55–161 s）。
- 最优 U ≈ 6.0–6.2 m/s，略高于有波时的车流均速（论文为 7.5 m/s，本仿真整体车速偏低约 1.3 m/s）。
- 规律和论文一致：U 太低能消波但吞吐下降；U 略超过车流可承受的速度，波就会回来；关闭控制后波很快重现；PI 控制效果约为 FollowerStopper 的一半到三分之二。
- 所有运行都没有发生碰撞。

## 变体 A：你来开（2026-11-08 加入）

第一版的风险已经比较明确：最优点一旦找到，四项指标同时变好，没有需要取舍的地方，可玩性只剩“发现”和“围观”。
变体 A 把玩法从“调参数”改成“亲手开车”，检验技巧型玩法。

**假设**：玩家亲手用油门和刹车驾驶 CyberCab 吸收停走波，是一种能练习、会越玩越好的技巧。
**判断标准**：同一组司机连续挑战 3 次，成绩逐次变好，并且玩家想再来一次，或者想赢过算法。

**玩法**：

- 模式里选「你来开」可以自由驾驶；点「开始挑战：你来开 120 秒」进入计分挑战。
- 挑战流程：先快进 120 秒，让纯人类车流自然形成停走波；然后暂停，等你按 ↑ / W 或点「油门」开始；以实时速度开 120 秒。
- 操作：↑ / W 油门，↓ / S 刹车，都不按 = 滑行（约 −0.3 m/s²）。踏板是渐进的，每秒最多变化 3 个单位，轻点就是轻踩。手机上可以按住屏幕上的「油门」「刹车」按钮。
- 驾驶视图：前方 80 m 展开成直线，显示每辆车的车速；速度表上有“前车速度”和“参考均速”两条标线。参考均速是接管前最后一圈的车流平均速度，对应论文实验 B 中观察员报给司机的数字。
- AEB（自动紧急制动）：车距小于 2.5 m，或者需要的减速度超过 3 m/s² 时自动接管。它保证不会追尾，但每介入一次都会计数。
- **成绩**：这 120 秒内全环路车速标准差 σ，越低越好。吞吐量必须不低于人类基准的 98%，防止玩家靠带着全体龟速行驶来刷低 σ。
- **对照组**：开始挑战时，用同一组司机、同样的前 120 秒，在后台把后 120 秒各跑一遍：
  - 人类基准：CyberCab 继续当人类司机；
  - 算法最佳：FollowerStopper 分别用 U = 5.8 / 6.0 / 6.2 跑，在吞吐量达标的结果里取 σ 最低的一个。
- 评价分五档：太慢（吞吐不达标）/ ★ 赢过算法 / 平稳达成（σ < 1.0）/ 有效果，还没赢算法（σ < 人类基准 × 0.7）/ 波还在。

**难度标定**：在 Node 里用一个模仿人手操作的规则机器人测试。它的规则是：前车距离不安全就刹车，低于 6.0 m/s 就加油门，高于 6.2 m/s 就轻刹，并带 0.25 s 反应延迟。

| 对象 | 120 s 窗口 σ | 180 s 窗口 σ |
|---|---|---|
| 人类基准 | 2.4–3.2 | 2.4–3.1 |
| 算法最佳（FollowerStopper） | 1.2–1.6 | 1.0–1.3 |
| 规则机器人 | 1.2–1.7 | 1.0–1.4 |

结论：一个“会开但不聪明”的司机大约能追平算法，赢不了也输不多。真人玩家能看到整个环路，可以比只看前车的算法更早预判停走波，这正是技巧的天花板所在。在浏览器里用真实键盘事件跑完整场挑战，评价、对照组、AEB 计数、中途切模式中断挑战都工作正常，没有发生碰撞。

## 发现（试玩后填写）

_待试玩。原版（调参）和变体 A（你来开）分别记录：假设是否成立、最好的时刻、最差的时刻、意外、PROCEED / PIVOT / KILL。_

试玩前的设计分析（不是试玩结论）：原版的可玩性主要来自“以小博大”的观赏性和“想让大家快，自己先慢”的反直觉顿悟；它的弱点是最优解一家独大、一次就解完、操作单薄、反馈慢。
